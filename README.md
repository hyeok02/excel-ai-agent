# excel-ai-agent

AI-powered platform for parsing, analyzing, updating, and querying complex Excel workbooks with traceable cell-level insights

## Workspace

```text
excel-ai-agent/
├── FE/            # React + Vite + TypeScript + Tailwind CSS
├── BE/       # Spring Boot
└── AI/    # Python Excel AI Agent
```

## Tech Stack

| 영역 | 기술 |
|---|---|
| Frontend | React, Vite, TypeScript, Tailwind CSS |
| Backend | Java, Spring Boot, Spring Data JPA, Gradle |
| Database | Oracle 21c, Flyway |
| Test | JUnit, MockMvc, H2 |
| AI Service | Python 기반으로 개발 예정 |
| Development | Docker, GitHub |
